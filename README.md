# Tap-25
A fun, fast-paced tapping game designed to test focus and reaction speed — and secretly troll students during exams by unlocking a surprise hidden message/video.  Players must tap numbers 1 to 25 in order as fast as possible. After finishing, a secret message/video is revealed.
🚀 Features
🎯 Gameplay

Tap numbers 1 → 25 in correct order

Randomized grid every game

Real-time stopwatch

Win screen with final time

Fun challenges for friends/classmates

🔐 Secret Reveal

After completing the game, players unlock a hidden message/video

Works as a prank for classrooms, exam halls, or friends

Local video file included (video.mp4)

🎨 UI & Experience

Smooth animations

Tailwind CSS glass-morphism card

Icons powered by Lucide

Fully responsive (mobile ready)

Clean, modern design

📂 Project Structure
index.html      # Main game + UI + logic
video.mp4       # Secret revealed video (local file)


Everything is compact in one HTML file for fun use and sharing.

🧠 How the Game Works

User sees a welcome screen

They tap numbers 1 → 25

Timer counts how fast they play

When finished, the "secret message" button appears

After clicking, a video pops up (perfect for trolling)

The game switches between 4 states:

welcome

playing

won

reveal
(handled via screen switching logic)

▶️ How to Run

Just open the file:

index.html


Or drag it into Chrome/Edge/Firefox.
Works offline — no backend required.
